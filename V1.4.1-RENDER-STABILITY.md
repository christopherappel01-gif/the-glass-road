# V1.4.1 Render stability pass

This build keeps the V1.4 landing-page and dice-result UI polish and adds deployment hardening:

- Pins Node to the 20.x LTS line rather than allowing any Node >=18 runtime.
- Pins Express 4.21.2 and Socket.IO 4.8.1 exactly.
- Sets explicit HTTP keep-alive/header timeouts for reverse-proxy hosting.
- Logs unhandled promise rejections and uncaught exceptions instead of silently losing the process during prototype playtests.

The V1.4 UI changes remain client-side only.
