# V1.4.4 – Sharper Scene Art Pass

This pass addresses reports that some story images still appeared fuzzy or low-resolution. The root cause was that several scene asset files were themselves soft/blurred, not just CSS scaling.

Changes:
- Re-mapped the blurriest scene beats to sharper existing artwork already included in the build.
- Focused on the worst-affected routes and encounters: pine-route scenes, river-route scenes, Broken Span phase art, tunnel/ridge scenes, and some Hollowmere interiors.
- Lightened the art overlay slightly so scene detail reads more clearly in the story panel.

This keeps the V1.4 load-page improvements, V1.4.1 Render stability updates, V1.4.2 portrait fixes, and V1.4.3 dice/hint fixes.
