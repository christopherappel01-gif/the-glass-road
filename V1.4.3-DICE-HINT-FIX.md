# V1.4.3 — Dice Reliability + Persistent Hints

## Dice roll reliability
- Added an immediate server `rollStarted` confirmation when a roll request reaches the server.
- Roll buttons now have explicit `type="button"` behavior.
- Roll requests use a Socket.IO acknowledgement timeout and automatically unlock for a safe retry if the server does not respond.
- A re-rendered challenge keeps the visible `Rolling…` state rather than losing the request state.
- Disconnects clear stale roll locks so a reconnect cannot leave the dice button permanently inert.
- Fixed a race where a completed state update could clear the pending request before the acknowledgement callback finished.

## Persistent hints
- Private character insights no longer disappear on a timer.
- In-game notification/hint callouts no longer disappear on a timer.
- Both now remain visible until the player clicks a large integrated × close button, matching the dice-result interaction.

## Existing V1.4.2 fixes retained
- Non-Knight hero portrait asset reliability fixes.
- V1.4 load-page polish and in-game voice-chat messaging.
- V1.4.1 Render runtime stability settings.
