# Deploy without Terminal

1. Create a new GitHub repository for **The Glass Road**.
2. Unzip this package and upload the contents of the unzipped folder to the repository root.
3. In Render, create a new Web Service from that repository.
4. Use `npm install` as the Build Command and `npm start` as the Start Command.
5. Use `/health` as the Health Check Path.
6. Deploy.
7. Open the game in two browsers/devices and test room creation, joining, voice chat, one challenge, and reconnection.
