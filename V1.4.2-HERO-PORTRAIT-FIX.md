# V1.4.2 Hero portrait fix

- Hero portrait requests now use root-absolute `/assets/...` URLs.
- Portrait URLs include a build cache key so browsers/CDNs do not keep stale class artwork.
- Every class portrait has a class-specific fallback image if a selected variant fails to load.
- Applies to character creation, portrait picker, lobby/player cards, opening company panel, and hero sheet.
- Keeps the V1.4 load-page polish, larger dice-results close control, and V1.4.1 Render stability changes.
